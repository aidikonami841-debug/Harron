# Finance App (React Native)

Aplikasi rekap keuangan fleksibel untuk individu maupun toko/bisnis dengan sistem multi-wallet.

## Cara Menggunakan:
1. Extract file zip ini ke folder project pilihan Anda di komputer.
2. Buka folder menggunakan **Visual Studio Code**.
3. Jalankan terminal di VS Code dan ketik:
   ```bash
   npm install
   ```
4. Jalankan aplikasi:
   - Untuk Android: `npx react-native run-android`
   - Untuk iOS: `npx react-native run-ios`
